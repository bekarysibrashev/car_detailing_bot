# 🚗 Detailing Center Bot

Telegram-бот для детейлинг-центров и автомастерских. Клиент отправляет фото автомобиля, выбирает цвет и тип покрытия — бот генерирует реалистичный результат с помощью ИИ. Помогает продавать услуги кузовной покраски и винилирования ещё до визита клиента.

---

## Возможности

- 14 цветов на выбор + 8 типов покрытия (глянец, матовое, хром, карбон, хамелеон и др.)
- 112 комбинаций цвет × покрытие
- Реалистичный результат: бот не трогает диски, стёкла, пластик, фары — только металл кузова
- FSM-диалог: фото → цвет → покрытие → результат
- Кнопки «Другой цвет» и «Новое фото» после результата

## Как работает ИИ

Бот использует модель **FLUX.1-Kontext-dev** — диффузионную image-to-image модель от Black Forest Labs, специализированную на контекстном редактировании изображений.

### Процесс генерации

```
Фото пользователя
       ↓
Составляется промпт (цвет + тип покрытия)
       ↓
HuggingFace InferenceClient → fal-ai (провайдер)
       ↓
FLUX.1-Kontext-dev (image-to-image)
       ↓
Pillow сохраняет результат в JPEG
       ↓
Бот отправляет фото обратно
```

### Промпт-инжиниринг

Промпт составлен так, чтобы модель:

1. **Определила** только металлические окрашенные панели кузова
2. **Исключила** пластиковые бамперы, решётки, диски, резину, стёкла, фары, хром
3. **Заменила** только заводской цвет кузова на выбранный
4. **Сохранила** освещение, отражения, тени, ракурс и геометрию автомобиля

Такой подход даёт фотореалистичный результат без артефактов на деталях, которые не красятся.

### Retry-логика

При ошибке на стороне HuggingFace бот автоматически повторяет запрос до 3 раз с паузой 4 секунды между попытками.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/YOUR_USERNAME/detailing-bot.git
cd detailing-bot
```

### 2. Установить зависимости

```bash
pip install aiogram python-dotenv Pillow huggingface_hub
```

### 3. Создать файл `.env`

```env
BOT_TOKEN=ваш_токен_от_BotFather
HF_TOKEN=ваш_токен_от_HuggingFace
```

Получить токены:
- **BOT_TOKEN** — [@BotFather](https://t.me/BotFather) в Telegram
- **HF_TOKEN** — [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) (нужен токен с правом `Inference`)

### 4. Запустить

```bash
python bot.py
```

## Структура проекта

```
├── bot.py          # Запуск: Bot, Dispatcher, polling
├── handlers.py     # Все хэндлеры (команды, фото, колбэки)
├── keyboards.py    # Inline-клавиатуры
├── states.py       # FSM-состояния (CarState)
├── config.py       # Константы: COLORS, COATINGS, пути
├── ai.py           # Генерация через HuggingFace
├── database.py     # SQLite: пользователи и запросы
├── .env            # Токены (не коммитить!)
├── uploads/        # Входящие фото от пользователей
└── outputs/        # Результаты генерации
```

## Советы по качеству результата

Лучший результат достигается если:
- фото сбоку или три четверти
- хорошее равномерное освещение
- автомобиль занимает большую часть кадра
- нет посторонних объектов перед машиной
- кузов однотонный (не уже с рисунком/винилом)
